# Bank Account System (Java Encapsulation)

## Description

This project demonstrates encapsulation in Java by protecting bank account data and allowing access only through public methods.

## Features

* Private accountNumber and balance variables
* Deposit operation
* Withdrawal operation with validation
* Balance access using getter method
* User input using Scanner

## Files

* BankAccount.java — Contains account data and methods
* Main.java — Handles user input and performs operations

## Concepts Used

* Encapsulation
* Classes and Objects
* Private data members
* Public methods
* Constructor

## How to Run

Compile:
javac Main.java BankAccount.java

Run:
java Main

## Outcome

Sensitive data like balance cannot be accessed directly and can only be modified using controlled methods.
